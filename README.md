# Häkelplaner

Eine deutschsprachige, installierbare Web-App zum Entwerfen von Filet-Kästchenmustern und Erzeugen einer Reihenübersicht.

## Auf GitHub Pages veröffentlichen

1. Lege auf GitHub ein Repository mit dem Namen `haekelplaner` an. Wenn du GitHub Free nutzt, muss das Repository für GitHub Pages öffentlich sein.
2. Lade **alle Dateien aus diesem Ordner** direkt in das Stammverzeichnis des Repositorys hoch. `index.html` muss dort direkt liegen.
3. Öffne im Repository **Settings → Pages**.
4. Unter **Build and deployment** wähle **Deploy from a branch**, danach den Branch `main` und den Ordner `/(root)`, und speichere.
5. Nach der Veröffentlichung zeigt GitHub Pages die Webadresse an. Öffne sie am Handy.
6. Android: Browsermenü → **App installieren** oder **Zum Startbildschirm**. iPhone: in Safari **Teilen → Zum Home-Bildschirm**.

Die App speichert den letzten Entwurf im lokalen Speicher des jeweiligen Geräts. Nutze **Muster speichern**, wenn du eine Sicherung möchtest oder dein Muster auf ein anderes Gerät übertragen willst.

Nach dem ersten Öffnen kann die App offline starten. Die erste Installation und das erste Laden benötigen eine Internetverbindung.
